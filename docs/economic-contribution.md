# The economic contribution, stated as economics

Drafted for the camera-ready; the manuscript currently carries these as
scattered sentences.

1. **The endowment is partially verifiable.** Dye's friction is that a
   receiver cannot tell an empty endowment from a concealed one. Instrument
   vintages make one side of that verifiable for free: `E ⊆ A`, with `A`
   computable by anyone from public dates. This is a verification technology
   the disclosure literature has not had.

2. **The verifying variable is not excludable from the receiver's valuation.**
   The same dates that bound the endowment move the measure of standing the
   receiver would use to price silence. Verification and valuation are coupled
   through `t - tau`, so the technology that narrows the Dye pooling
   contaminates the inference it was meant to enable. This is the paper's
   result, read as information economics rather than as measurement.

3. **Consequence: strategic selection is unidentified from availability
   alone.** Not for want of data or labels, but because the exclusion
   restriction fails by construction (docs/proposition.md). Any future audit
   built on "could have reported but did not" inherits this.

4. **The lever is the reporting standard, not the estimator.** A provider that
   reports a benchmark once has shown it holds the harness; a convention of
   carrying a benchmark set across a family's releases converts later silence
   from pooled (empty-or-concealed) to informative, narrowing Dye's pooling
   without mandating any new disclosure. Incentive-compatible in the weak
   sense that it asks nothing a provider has not already done once, and it
   grows exactly the record the within-family drop design needs.

A formal model of provider reporting with this verification structure (sender
holds `E`, receiver observes `D` and the public dates, standing measured on a
calendar-coupled pool) is the natural EC-style follow-up; the counterexample
in the proposition file is its impossibility half.
