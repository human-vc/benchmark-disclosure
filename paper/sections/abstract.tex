\begin{abstract}
Model providers choose which benchmark results appear in a release document, and an
independent evaluator scores the same models on many more, so what was left out can be
examined. Doing that requires knowing which results a provider could have reported, and
benchmark publication dates supply the bound: an instrument built after a model shipped was
never available to it. The comparison this invites, between benchmarks a provider passed
over and benchmarks that did not yet exist, fails as a check on itself. Across 146 releases
the second group already stands 12.23 percentile points below the first, computed without
using a single disclosure label. The date deciding whether a benchmark could have been
reported also decides where a model sits within that benchmark's coverage, and standing
measured against contemporaries moves with that position. The same failure appears on a
leaderboard we did not build: over fourteen releases of HELM Lite, 24 models keep
bit-identical scores while every published win rate moves and five pairs change order, and a
companion leaderboard from the same team with an absolute headline shows no movement at all.
We report no estimate of how much selective disclosure occurs, because measuring it needs a
measure of standing that does not inherit the timing which decides what could have been
disclosed.
\end{abstract}
